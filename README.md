📩 **Can BERT Tell the Difference Between Spam & Legitimate Emails? I Put It to the Test.**

Recently, I’ve been diving deeper into **Deep Learning and NLP**, and I wanted to understand how **BERT** could be applied to a practical problem.

So, I worked on an **Email Spam Classification project using BERT with TensorFlow/Keras**.

The project took me through the complete NLP pipeline — from preparing and balancing the dataset to fine-tuning a classification model and evaluating its performance.

Along the way, I explored:

🔹 BERT preprocessing and encoding
🔹 768-dimensional contextual representations
🔹 Handling class imbalance through downsampling
🔹 Dropout and its role in reducing overfitting
🔹 Sigmoid activation for binary classification
🔹 Adam optimizer and Binary Cross-Entropy loss
🔹 Confusion Matrix and Classification Report

📊 **Project Outcome:**
The BERT-based classifier achieved an **F1-score of approximately 90%**, demonstrating strong performance in distinguishing **spam emails from legitimate (ham) emails**.

More importantly, this project helped me understand what happens behind the scenes when **BERT converts text into contextual information and how that representation is used for classification**.

The biggest takeaway for me was that understanding **why each component is used** is much more valuable than simply implementing the code.

This project has strengthened my understanding of **BERT, Transformers, and practical NLP workflows**, and I’m looking forward to applying these concepts to more real-world problems.

**One project, one concept at a time. 🚀**
